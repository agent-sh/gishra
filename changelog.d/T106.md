- Sandboxed claude and codex agents cannot read the user's credential stores: gh, claude, codex, docker, npm, pypi, cargo, netrc, git-credentials, kube, gcloud, azure, ssh and aws. Before, claude hid only `~/.ssh` and `~/.aws` and codex hid none, so a worker could read the gh login, the model credentials and registry tokens and send them anywhere. A store holding the agent's house rules, such as `~/.codex/AGENTS.md`, hides its other entries. Sandboxed homes no longer link `.config/gh`; gh uses the handed `GH_TOKEN`.
