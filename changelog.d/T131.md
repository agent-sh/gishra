- Gate commands (tests, proof, clean, local CI and the merge head check) run with `TMPDIR`, `TMP` and `TEMP` set to a directory under the gate temporary root, and the gate removes it with its worktree. Test helpers and the child processes they start no longer leave `tower-crane-*` directories in the system temporary directory.
- Test fixtures stop the processes they start in teardown even when the test fails before it reads their pids (the broker and supervision tests).
- The browser test helper starts Chrome from the first directory whose profile socket path fits, since a gate's temporary root can be too deep for it. The profile is still removed when the browser closes.
