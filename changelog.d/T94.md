- Worker spawn uses claim readiness for task status, dependencies, stack state, locks and worker slots, and refuses with the same reason before launch. Claim and spawn refresh existing stack membership from GitHub, while transient API errors remain retryable and do not disable stacks. A bottom PR GitHub reports in a stack merges through `gh stack merge`, and a dependent whose PR head GitHub moved after a lower merge takes the new head and needs its gates again. A stacked rework whose branch is gone resumes from its own pushed head, and a branch that already contains its dependency head is used as it is.
